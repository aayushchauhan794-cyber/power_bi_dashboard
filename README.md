## Introduction

this dashboard was created for **job seekers, Job Transitioners, and job swappers** to solve a comman problem: information about the data job market is scattered and hard to grasp. Using a real-world dataset of 2024 data science job posting (including titles, salaries, and locations), this project provides a single, easy-to-use interface to explore market trends and compensation.
